# T-Office Application Features

This document provides a comprehensive overview of all pages and features available in the T-Office application.

## Dashboard

**Path:** /dashboard

**Description:** Central hub for user activities and overview

### Features:

- **Activity Feed**: Displays recent user activities and system events
- **Quick Stats**: Shows key metrics and statistics relevant to the user
- **Navigation Hub**: Provides quick access to frequently used sections

## Chat

**Path:** /chat

**Description:** Internal team communication system

### Features:

- **Anonymous Chat**: Allows users to communicate anonymously with team members
- **Direct Messaging**: Send private messages to specific users
- **Channel Rooms**: Join topic-based discussion channels

## Clock

**Path:** /clock

**Description:** Time tracking and attendance management

### Features:

- **Clock In/Out**: Record work hours with timestamp logging
- **Attendance History**: View past clock-in/clock-out records
- **Reports**: Generate attendance reports for managers

## Profile

**Path:** /profile

**Description:** User personal information and settings

### Features:

- **Personal Information**: View and update personal details
- **Password Management**: Change account password securely
- **Notification Preferences**: Configure notification settings

## Settings

**Path:** /settings

**Description:** Application configuration and preferences

### Features:

- **Theme Selection**: Choose between light/dark themes
- **Language Preferences**: Select preferred language for interface
- **Privacy Controls**: Manage privacy and data sharing settings

## HR Management

**Path:** /hr

**Description:** Human resources operations and employee management

### Features:

- **Employee Directory**: Browse and search all employees
- **Onboarding**: Manage new employee onboarding processes
- **Queries**: Handle employee HR-related questions and requests
- **User Management**: Create, update, and manage employee accounts

## Admin Panel

**Path:** /admin

**Description:** Administrative controls and system management

### Features:

- **Database Management**: View and manage database tables and records
- **User Administration**: Manage user accounts, roles, and permissions
- **System Logs**: Monitor system activities and audit trails
- **Features Documentation**: Comprehensive listing of all application features

## Approvals

**Path:** /admin/approvals

**Description:** Review and approve pending requests and submissions

### Features:

- **Certificate Approvals**: Review and approve user certificate submissions
- **Document Verification**: Verify authenticity of submitted documents
- **Approval History**: View past approval decisions and records

## Inventory

**Path:** /inventory

**Description:** Product and stock management system

### Features:

- **Product Catalog**: Manage product listings and information
- **Inbound Tracking**: Track incoming inventory shipments
- **Storage Management**: Manage stored inventory and locations
- **Outbound Processing**: Process outgoing inventory requests

## Resources

**Path:** /resources

**Description:** Knowledge base and documentation

### Features:

- **Wiki**: Department-specific documentation and guides
- **Resource Library**: Access to shared files and documents
- **Policy Documents**: Company policies and procedure manuals

## Authentication

**Path:** /login, /signup

**Description:** User authentication and account creation

### Features:

- **Login**: Secure user authentication with credentials
- **Signup**: New user registration and account creation
- **Password Recovery**: Reset forgotten passwords via email
