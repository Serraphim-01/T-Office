## 1. Dashboard

The **Dashboard** is the main landing page after a user logs in. It provides a high-level overview of the application and key metrics.

---

## 2. Anonymous Chat

The **Anonymous Chat** is a real-time communication tool that allows users to have open and honest discussions without revealing their identities.

-   **Anonymity:** Users are assigned random anonymous names.
-   **Session-Based:** Messages are stored locally and cleared when the user logs out.

---

## 3. Profile

The **Profile** page allows users to view and manage their personal information.

---

## 4. Onboarding

The **Onboarding** section is a learning management system designed to help new employees get acquainted with the company.

-   **Lesson Dashboard:** The main onboarding page displays a list of all available lessons and the user's progress (Not Started, In Progress, Completed).
-   **Lessons:** Each lesson provides information on a specific topic. The current lessons are:
    -   **Lesson 1: The Company Organogram:** An overview of the company's structure.
    -   **Lesson 2: Organization Workflow:** An explanation of the standard project workflow.
    -   **Lesson 3: Departments and their Responsibilities:** A breakdown of each department's role.
-   **Quizzes:** At the end of each lesson, there is a quiz to test the user's knowledge. The user's score is displayed upon completion.
-   **Progress Tracking:** The user's progress and quiz scores are saved in the browser's local storage.

---

## 5. Attendance

The **Attendance** page allows users to track their work attendance and manage their sign-in/sign-out times.

-   **Sign-In/Sign-Out:** A button on the sidebar allows users to sign in and out for the day. This button is only active during specific, configurable time windows.
-   **Time Configuration:** The attendance page has settings to configure the sign-in and sign-out time windows (default: 7:00-8:30am for sign-in, 3:30-5:00pm for sign-out).
-   **Attendance History:** A calendar on the page displays the user's attendance history.

---

## 6. Report

The **Report** page provides a summary of the user's activity within the application.

-   **Activity Feed:** It displays a list of all the user's logged activities, such as pages viewed and sign-in/out actions.
-   **Time Filters:** Users can filter their activity by day, week, month, or year.

---

## 7. Admin

The **Admin** section provides tools for administrators to manage the application.

-   **Roles:** Manage user roles and permissions.
-   **Departments:** Manage the company's departments.

---

## 8. HR

The **HR** section provides tools for the Human Resources department.

-   **Employee Database:** A centralized system for storing and managing all employee information.
-   **Time and Attendance:** A tool for tracking employee hours and managing absences.
-   **Reporting and Analytics:** A dashboard for generating reports and analytics on HR metrics.

---

## 9. Sales

The **Sales** section provides tools for the sales team.

-   **Contact Management:** Organize and manage customer and prospect information.
-   **Pipeline Management:** A Kanban-style board to visualize and track the sales pipeline.
-   **Task Automation:** A tool for automating repetitive sales tasks.
-   **Document Management:** A central repository for storing and managing sales-related documents.
-   **Goal Setting & Tracking:** A dashboard for setting and monitoring sales goals.

---

## 10. Audit

The **Audit** section provides tools for the audit team.

-   **Audit Planning and Scheduling:** A tool for defining and scheduling audits.
-   **Risk Assessment Tools:** A tool for identifying, scoring, and managing risks.

---

## 11. Tech Team

The **Tech Team** section provides tools for the technical team.

-   **Licensing:** Manage software licenses.
-   **Accounts:** Manage customer accounts.
-   **OEM Partners:** Manage OEM partner relationships.
-   **Deals:** Manage tech team deals.

---

## 12. Activity Bar

The **Activity Bar** is a right-side panel that displays a real-time feed of the user's most recent activities within the application, providing transparency and a quick overview of recent actions.
